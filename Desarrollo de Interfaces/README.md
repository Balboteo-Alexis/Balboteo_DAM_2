# 🎨 Desarrollo de Interfaces

### 2º DAM · IES Playamar

Repositorio de los ejercicios y proyectos realizados en la asignatura **Desarrollo de Interfaces**, del segundo curso de Desarrollo de Aplicaciones Multiplataforma.

**Tecnologías:** TypeScript · Angular · HTML · CSS · Bootstrap

---

## 📂 Proyectos

### 🅰️ my-app — Proyecto Angular

Proyecto principal de la asignatura, en el que trabajamos la creación de componentes y el desarrollo de interfaces interactivas utilizando **Angular y TypeScript**.

Durante las clases hemos desarrollado distintos componentes:

- **Contador:** incremento, decremento y reinicio de valores.
- **Héroe:** visualización y modificación de propiedades de un personaje.
- **Lista:** gestión dinámica de elementos de un array.
- **Centro educativo:** muestra los datos del IES Playamar y permite intercambiarlos por los del IES Jacaranda.

También utilizamos **Bootstrap** para mejorar la presentación de las interfaces.

### 📘 Ejercicios de TypeScript

Ejercicios prácticos para aprender los fundamentos de TypeScript: clases, interfaces, arrays, funciones, objetos y genéricos.
